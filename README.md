# AI Tutor 🤖

This is an AI Tutor project built using Python.

## 🚀 Features

* Answers questions
* Explains concepts
* Simple and fast

## 🛠️ Tech Stack

* Python
* Groq API
* dotenv

## ▶️ How to Run

1. Install dependencies:
   pip install -r requirements.txt

2. Run the app:
   python main.py

## 📁 Files

* app.py → main app logic
* main.py → entry point
* .env → API key (not uploaded)

## ⚠️ Note

Do not upload your API key publicly.
